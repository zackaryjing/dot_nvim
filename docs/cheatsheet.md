# Neovim 个人速查表

## 消息

| 快捷键或命令 | 用途 |
| --- | --- |
| `<leader>snh` | 查看 Noice 消息历史 |
| `<leader>snl` | 查看最后一条 Noice 消息 |
| `<leader>sna` | 查看全部 Noice 消息 |
| `<leader>n` | 查看 Snacks 通知历史 |
| `<leader>un` | 关闭浮动通知 |
| `:messages` | 查看 Neovim 原生消息历史 |

`<leader>` 默认为空格键。

## 命令行

| 快捷键 | 用途 |
| --- | --- |
| 输入 `:` 命令时按 `↓` / `↑` | 浏览较新 / 较旧的历史命令 |
| 输入 `:` 命令时按 `<C-n>` / `<C-p>` | 选择下一个 / 上一个候选命令 |

## 终端

| 快捷键 | 用途 |
| --- | --- |
| `<leader>ft` | 打开或隐藏项目根目录终端 |
| `<leader>fT` | 打开或隐藏当前工作目录终端 |
| `<leader>t` | 快速聚焦或隐藏项目根目录终端 |
| `<C-h/j/k/l>` | 在左 / 下 / 上 / 右窗口之间移动 |

Snacks 底部终端固定为 10 行高，以上终端快捷键打开的是同一套可退出的终端窗口。

## 文件浏览器

Snacks Explorer 的宽度固定为 30 列。

## 主题

| 快捷键 | 用途 |
| --- | --- |
| `<leader>ub` | 在 dark / light 背景之间切换 |
| `<leader>uC` | 打开 colorscheme 选择器并预览主题 |

默认使用 `tokyonight-day`。个人配置将其主编辑区背景覆盖为纯白色，配置位于
`lua/plugins/colorscheme.lua`。

## 注释

| 快捷键 | 用途 |
| --- | --- |
| `gcc` | 注释或取消注释当前行 |
| 可视模式中按 `gc` | 注释或取消注释选中区域 |
| `gcap` | 注释或取消注释当前段落 |
| `<C-/>` | 注释或取消注释当前行 / 可视选区 |

在注释后按 `Enter` 或使用 `o/O` 新开一行时，不会自动延续注释符。

## 跳转

| 快捷键 | 用途 |
| --- | --- |
| `<leader>j` | 使用 Flash 在可见范围内快速跳转 |
| `s` | 删除当前字符并进入 Insert 模式，保留 Vim 原生行为 |
| `<C-Space>` / `<BS>` | 按 Treesitter 结构扩大 / 缩小选择范围 |
| `f/F/t/T{字符}` | 查找字符；每次开始新查找，使用 `;` / `,` 重复上次查找 |
| Insert 模式下按 `<M-a>`（`Alt-a`） | 移动到当前行末尾并保持 Insert 模式，便于补上右括号等行尾内容 |

## Snippet

| 操作 | 用途 |
| --- | --- |
| 在 C++ 文件中输入 `ltcd` 并确认补全 | 插入剪贴板中的 Solution，并将光标停在 problem 位置 |
| 在 Python 文件中输入 `mltp` 并确认补全 | 插入机器学习题解模板，包含剪贴板内容、`main()` 入口以及当前日期和时间 |
| 输入 `tv` 并确认补全 | 插入 `temp_vector()`，并将光标停在括号内 |
| `Tab` | 跳转到下一个 snippet 占位符 |
| `Shift-Tab` | 跳转到上一个 snippet 占位符 |

## C++

| 快捷键 | 用途 |
| --- | --- |
| `<leader>rr` | 保存、编译并在可用的独立终端运行当前 C++ 文件，产物写入项目的 `output/` |
| `<leader>rc` | 保存、编译并在底部终端运行当前 C++ 文件，产物写入项目的 `output/` |
| `<leader>cf` | 使用 `clang-format` 格式化当前文件 |
| `gd` | 使用 `clangd` 跳转到定义 |
| Visual 选中表达式后输入 `:Wvar` | 替换为 `cout << "表达式: " << 表达式 << endl;` |
| Visual 选中表达式后输入 `:Wline` | 替换为 `cout << 表达式 << endl;` |

运行窗口会显示编译结果、程序输出和退出码。程序运行时可以直接输入 `cin` 内容。
使用 `<leader>rr` 时，程序退出或编译失败后按 `Esc` 关闭独立终端。
配置会选择可用的最高版本 C++ 编译器和其支持的最高语言标准；在 WSL 上优先使用
Windows Terminal，找不到受支持的外部终端时自动退回底部运行窗口。
使用 `<C-j>` 从代码窗口进入底部运行窗口，使用 `<C-k>` 返回代码窗口。

## 剪贴板与补全

| 快捷键 | 用途 |
| --- | --- |
| `<leader>p` | 粘贴系统剪贴板内容 |
| `vag` | 使用 mini.ai 的 entire-file 文本对象选择整个文件 |
| `yag` | 直接将整个文件复制到默认寄存器 |
| `vag` 后按 `<leader>y` | 将整个文件复制到系统剪贴板 |
| 在可视模式中按 `<leader>y` | 将选中内容复制到系统剪贴板 |
| `Tab` | 确认当前补全候选；无补全候选时保留原有缩进功能 |
| `Shift-Tab` | 在 snippet 中反向跳转占位符 |

补全菜单不会在代码区显示 ghost text，补全菜单与文档窗口均使用完全不透明的背景。
使用 `.成员`、`->成员`、`::成员` 或 Lua `:成员` 时，snippet 候选会被过滤，
只保留适合成员访问的代码补全。

## 自动保存

普通文件会每 5 秒自动保存，并在窗口失焦或离开 buffer 时立即保存。
自动保存不会触发格式化；需要格式化时使用 `<leader>cf`。

## 空白字符显示

启用不可见字符显示时，Tab 显示为 `>`，不换行空格显示为 `+`；行尾普通空格不显示额外符号。

## 配置重载

修改 `lua/plugins/` 中的插件规格后，退出并重新启动 Neovim 最可靠：

```vim
:qa
```
